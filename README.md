# 🎮 GameHub

A responsive video game discovery application that helps users explore and discover games across different genres and platforms.

**[Live Demo](https://gamehub-nextjsproject.vercel.app/)**

## ✨ Features

- **Game Search:** Find games by name.
- **Genre Filtering:** Explore games across different genres.
- **Platform Filtering:** Filter games by their supported platforms.
- **Sorting:** Organize games by popularity, rating, release date, and more.
- **Game Information:** View platform availability, Metacritic scores, and rating indicators.
- **Dark Mode:** Switch between dark and light themes.
- **Responsive Design:** Enjoy a seamless experience across different screen sizes.
- **Loading States:** Skeleton loaders for a smoother browsing experience.

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Chakra UI
- Axios
- React Icons
- [RAWG Video Games Database API](https://rawg.io/apidocs)

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- A RAWG API key ([Get one here](https://rawg.io/apidocs))

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/moha-gh-mmad/GameHub.git
   ```

2. Navigate to the project directory:

   ```bash
   cd GameHub
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env.local` file in the root directory and add your RAWG API key:

   ```env
   VITE_RAWG_API_KEY=your_rawg_api_key
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

### Build for Production

```bash
npm run build
```
